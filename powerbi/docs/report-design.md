# Report design - three pages

Canvas 1280 × 720, theme `theme/genesys-audit-theme.json`. Every page starts
with a row of filters, like the Genesys Audit Viewer, and the **Date** slicer
is synced across all three pages. All three pages are generated by
`tools/build_pbip.py` (`build_pages()`); this page describes them.

Times are local: `EventDateTimeLocal`, from `LocalUtcOffsetHours` plus
Australian daylight saving. The Date slicer filters on the local day.

## 1. Audit Viewer

The Genesys *Admin > Audit Viewer*, in Power BI.

| Area | Visual | Fields |
|---|---|---|
| Filter row | Slicers | Date (between) · Service · Entity type · Action · Changed by · Entity. The dropdowns have a search box. |
| Top right | Card | `[Audit Events]`, the events matching the filters |
| Events | Table, newest first | Date / time · Changed by · Service · Action · Entity type · Entity · Changes (old → new) · Status · Application · IP address · Audit id |
| What changed | Table | For the event(s) clicked above: Date / time · Entity · Property · Old value · New value · Change (Added / Removed / Modified) · Related entity · Full property name |
| Help / freshness | Text + card | How to use the page; `[Latest Event Loaded]` |

* **Changed by** is the user's name. For integrations it is the OAuth client's
  name, from the client list.
* **Changes (old → new)** is `AuditEvents[ChangeSummary]`, every property and
  entity change of the event on one line.
* Clicking a row filters *What changed* through `AuditEvents -> AuditPropertyChanges`.
  Ctrl+click selects several rows.

## 2. Agent Presence

A page filter keeps only presence events (`AuditEvents[IsPresenceEvent] = true`).

| Area | Visual | Fields |
|---|---|---|
| Filter row | Slicers | Date · Agent · Changed by · Who changed it (agent themselves / another person / integration / system) |
| Cards | Card | `[Presence Changes]` · `[Agents Affected]` · `[Changed By Someone Else]` (another person + integration) |
| Trend | Stacked column | Presence changes per day, coloured by *Who changed it* |
| Changes | Table, newest first | Date / time · Agent · From · To · Changed by · Who changed it · Via (application) · Details (message) · Audit id |

## 3. API Usage & Clients

| Area | Visual | Fields |
|---|---|---|
| Filter row | Slicers | Date · OAuth client |
| Cards | Card | `[API Requests]` · `[API Errors]` (4xx + 5xx) · `[Rate Limited (429)]` · `[Active Clients]` · `[Last API Use]` (usage data up to) |
| Clients | Table | Client · Client id · Grant type · State · Requests · Errors · 429s · Error % · Audit changes · Last used · Created. Disabled or idle clients are listed with 0 requests. Click a client to filter the page. |
| Trend | Stacked column | API requests per UTC day by client |
| Endpoints | Table | Endpoint (method + URL template) · Requests · Errors · 429s · 5xx |
| What integrations changed | Table | Audit events made by OAuth clients: Date / time · Client · Service · Action · Entity · Changes · Audit id |
